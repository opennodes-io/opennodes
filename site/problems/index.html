Problem types

Errors, by name

OpenNodes registries, nodes and gateways report errors as RFC 9457 problem details (application/problem+json). The type is https://opennodes.io/problems/{name}, the title is the bare name, and detail says what went wrong in this case. Match on title.

HTTP/1.1 409 Conflict
Content-Type: application/problem+json

{"type": "https://opennodes.io/problems/price_changed", "title": "price_changed",
 "status": 409, "detail": "pinned 7, current 8"}

Nodes (ONP-4 invocation)

price_changed409The ONP-Card-Revision you priced against was superseded by one with different pricing. Re-fetch the card, re-check your spend policy, retry.
offering-mismatch409The ONP-Offering header no longer names the model behind this endpoint.
model-not-found404No offering (or, at a gateway, no registry match) for the requested model.
engine-error502The node's inference engine returned an error.
bad-json400The request body is not JSON.
unknown-receipt404No receipt with that id on this node.
unknown-challenge404No pending registration challenge with that token.

Registry (ONP-3)

namespace-mismatch403The card's reverse-DNS node id maps to a domain that the host serving the card does not control.
rate-limited429Too many registration or verification attempts from this address.
unknown-node404No node with that id in this registry.
unknown-offering404No offering with that node_id/offering_id.
missing-card-url400Registration body must be {"card_url": "…"}.
bad-probe-key400probe_key must be a string.
card-unfetchable422The registry could not fetch the node card.
card-invalid422The node card does not validate against the ONP-2 schema.
challenge-expired410The registration challenge expired; register again.
challenge-failed403Neither the HTTP nor the DNS TXT challenge was satisfied.
refresh-failed422Re-fetching the node's card failed.
wrong-state409The node is not in the tier this step requires (Stage B needs community).
admission-cooldown429Stage B ran recently for this node; detail says when the next run is allowed.
stale-card409The node changed its card revision during the qualification battery; retry.
not-delisted409Only a delisted node can be restored.
register-again409A registered node returns by registering again (POST /v0/nodes).
missing-steps400Estimate body must be {"steps": […]}.
bad-step400Each estimate step needs offering or select.
no-offering-matches404No offering matches the step's select.
missing-task400Recommend body must carry task (text) or features.
missing-catalog400Import body must carry {catalog} or {url}.
method-not-allowed405The MCP endpoint is stateless: POST JSON-RPC messages to it.

Gateways and routers

no-callable-offerings404Something matches the auto-routing model, but nothing this gateway can call: free registered nodes need no key, imported catalogs need a provider key.
all-candidates-failed502Every candidate offering failed; detail lists each error.
not-implemented501The gateway does not serve this profile yet.

Common

unauthorized401Missing or wrong bearer token.
forbidden403The route is loopback-only without an admin token.
not-found404No route for this method and path.
internal-error500Unexpected server error.
